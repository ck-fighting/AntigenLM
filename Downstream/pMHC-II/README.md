# pMHC-II Dataset README

This directory contains the pMHC-II downstream datasets, HLA-II sequence/embedding
dictionaries, and cached peptide embeddings used by the lightweight HLA-II
training/evaluation scripts.

## Current Modeling Pipeline

The current implementation is a standalone cached peptide embedding + ESM2
matching pipeline. It no longer depends on the older `DSCA-HLAII-main` code.

| Component | Current Implementation |
|---|---|
| Peptide encoder | Precomputed AntigenLM_distilled token embeddings from `data_cached/*.mmap`, hidden size `960`, default token length `34`. |
| MHC-II encoder | Precomputed ESM2 HLA-II chain embeddings from `data/hla_dict/hla_esm_dict.npy`, shape `(98, 100, 1152)`. |
| MHC-II alpha/beta handling | Alpha and beta ESM2 token embeddings are encoded with a shared chain encoder, concatenated on token dimension, then fused as one MHC-II representation. |
| Peptide-MHC fusion | Peptide token embeddings and fused MHC-II token embeddings are each passed through lightweight sequence encoders, then attention-pooled into vectors. |
| Optional MIL/window head | `--aggregation mil_window` scores every valid 9-mer peptide window, aggregates window logits with softmax or max pooling, and reports the 1-based predicted binding-core start. |
| Classifier | Interaction MLP over peptide vector, fused MHC-II vector, alpha/beta vectors, absolute differences, and elementwise products. |
| Classification loss | `BCEWithLogitsLoss` with automatic `pos_weight = negatives / positives`. For `benchmark.csv`, this is about `5.11`. |
| Contrastive loss | Supervised contrastive loss over the final peptide-MHC interaction embedding. |
| Total loss | `weighted_bce + contrastive_weight * supervised_contrastive`; default `contrastive_weight = 0.01`. |

Core files:

| File | Purpose |
|---|---|
| `precompute_peptide_embeddings.py` | Build AntigenLM_distilled peptide token embedding caches. |
| `pmhc_data.py` | CSV readers, peptide embedding mmap cache, HLA ESM2 dictionary, PyTorch dataset. |
| `model.py` | `AntigenLMESM2PMHCIIModel` explicit matching architecture. |
| `losses.py` | Weighted BCE + supervised contrastive loss. |
| `metrics.py` | AUC, AUPR, binary metrics, confusion matrix. |
| `train.py` | CV or single-split training. |
| `test.py` | Warm/cold evaluation, per-fold predictions, ensemble metrics. |

## Directory Layout

| Path | Description |
|---|---|
| `data/benchmark.csv` | Main labeled benchmark set used for training and 5-fold CV. |
| `data/benchmark_cv_seed1240/` | Pre-generated 5-fold split of `benchmark.csv`. |
| `data/warm-start-test.csv` | Warm-start external test set. HLA alpha-beta pairs are seen in benchmark, peptides are not. |
| `data/cold-start-test.csv` | Cold-start external test set. HLA alpha-beta pairs are unseen in benchmark. |
| `data/hla_dict/hla_full_seq_dict.csv` | HLA-II allele pseudo/full sequence dictionary used by the dataset loader. |
| `data/hla_dict/*.npy` | Precomputed HLA-II allele embedding dictionaries. |
| `data_cached/*AntigenLM_distilled_len34.npz` + `.mmap` | Current cached peptide token embeddings generated by `precompute_peptide_embeddings.py`. |
| `data_cached/*22_AntigenLM.npz` + `.mmap` | Legacy cached peptide embeddings retained for reproducibility of older runs. |
| `train.py`, `test.py`, `model.py` | Standalone cached peptide embedding + ESM2 + matching + contrastive training/evaluation code. |

## Label Definition

All labeled CSV files use:

| Column | Meaning |
|---|---|
| `peptide` | Peptide sequence. |
| `hla_alpha` | HLA-II alpha-chain allele name. |
| `hla_beta` | HLA-II beta-chain allele name. |
| `label` | Binary label: `1` is positive, `0` is negative. |
| `source_index` | Present only in CV split files; row index into `benchmark.csv` and cached embedding mapping. |

## Peptide Embedding Caches

The `.npz` files store metadata, including shape, dtype, and `row_to_unique`.
The `.mmap` files store the actual unique peptide embeddings.

| Cache Prefix | Unique Embedding Shape | Dtype | CSV Rows Mapped | Mmap Size |
|---|---:|---|---:|---:|
| `cached_pep_embeddings_benchmark_train_22_AntigenLM` | `(786175, 32, 768)` | `float16` | 942,602 | 36 GB |
| `cached_pep_embeddings_warm_test_22_AntigenLM` | `(178456, 32, 768)` | `float16` | 192,846 | 8.2 GB |
| `cached_pep_embeddings_cold_test_22_AntigenLM` | `(5116, 32, 768)` | `float16` | 5,262 | 240 MB |

The cache names reflect:

- `benchmark_train`, `warm_test`, `cold_test`: dataset split.
- `22`: amino-acid vocabulary/channel setting used by the original feature pipeline.
- `AntigenLM`: encoder used to generate peptide embeddings.

## Alignment Notes

The loader expects the CSV files and embedding cache files to stay aligned.

- `benchmark.csv` maps to `cached_pep_embeddings_benchmark_train_22_AntigenLM`.
- `warm-start-test.csv` maps to `cached_pep_embeddings_warm_test_22_AntigenLM`.
- `cold-start-test.csv` maps to `cached_pep_embeddings_cold_test_22_AntigenLM`.
- CV split `source_index` values point back to `benchmark.csv` rows and the benchmark peptide embedding cache mapping.

Do not reshuffle or rewrite the CSV files independently of their corresponding
`.npz`/`.mmap` caches unless the caches are regenerated at the same time.

## Training and Evaluation

Precompute AntigenLM_distilled peptide token embeddings first:

```bash
python precompute_peptide_embeddings.py --split all --max-length 34
```

Train all 5 CV folds:

```bash
python train.py --mode cv_train --folds all
```

Train selected folds:

```bash
python train.py --mode cv_train --folds 1,2,3
```

Train fold 1 with the 9-mer MIL/window head:

```bash
python train.py \
  --mode cv_train \
  --folds 1 \
  --aggregation mil_window \
  --window-size 9 \
  --mil-pooling softmax \
  --mil-temperature 1.0 \
  --init-checkpoint-dir ../trained_model/pMHC-II \
  --output-dir ../trained_model/pMHC-II-mil
```

Use `--mil-pooling max` for hard max pooling instead of softmax pooling.

Train a single random train/validation split from `benchmark.csv`:

```bash
python train.py --mode train
```

Evaluate warm-start and cold-start with all available fold checkpoints:

```bash
python test.py --eval-set both --folds all
```

Evaluate selected checkpoints:

```bash
python test.py --eval-set cold --folds 1,2,3
```

Evaluate a MIL/window checkpoint:

```bash
python test.py \
  --checkpoint-dir ../trained_model/pMHC-II-mil \
  --folds 1 \
  --output-prefix AntigenLM_MIL
```

MIL/window prediction CSVs include `core_start_1based` and `core_score`.
